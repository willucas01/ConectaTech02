1. O papel do CSS

CSS significa Cascading Style Sheets. Ele define cores, fontes, espaços, bordas e posicionamento. O HTML descreve o conteúdo; o CSS descreve como ele aparece.

Exemplo explicado

h1 { color: #38bdf8; }
p { font-size: 18px; }

Como praticar: copie o exemplo em um arquivo de estudos, identifique o papel de cada linha e experimente mudar valores, nomes ou textos. Depois compare o resultado com o comportamento esperado.

Erro comum: copiar sem entender o que cada parte faz. Antes de avançar, tente explicar com suas palavras para que serve o recurso apresentado.

2. Conectar CSS ao HTML

Use um arquivo .css separado e conecte-o no head com link. Assim, várias páginas podem compartilhar o mesmo estilo.

Exemplo explicado

<link rel="stylesheet" href="css/style.css">

Como praticar: copie o exemplo em um arquivo de estudos, identifique o papel de cada linha e experimente mudar valores, nomes ou textos. Depois compare o resultado com o comportamento esperado.

3. Seletores

Seletores de elemento afetam todas as tags daquele tipo. Classes começam com ponto e podem ser reutilizadas; IDs começam com # e identificam um elemento específico.

Exemplo explicado

.cartao { background: #123; }
#titulo { color: white; }
p { line-height: 1.6; }

Como praticar: copie o exemplo em um arquivo de estudos, identifique o papel de cada linha e experimente mudar valores, nomes ou textos. Depois compare o resultado com o comportamento esperado.

4. Cascata e especificidade

Quando regras entram em conflito, a origem, a importância, a especificidade e a ordem influenciam o resultado. Evite depender excessivamente de !important; prefira classes claras.

Exemplo explicado

p { color: gray; }
.destaque { color: blue; }

Como praticar: copie o exemplo em um arquivo de estudos, identifique o papel de cada linha e experimente mudar valores, nomes ou textos. Depois compare o resultado com o comportamento esperado.
