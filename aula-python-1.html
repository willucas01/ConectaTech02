1. O que é Python

Python é uma linguagem de programação conhecida pela sintaxe legível. É usada em automação, análise de dados, web e muitas outras áreas.

Exemplo explicado

print("Olá, mundo!")

Como praticar: copie o exemplo em um arquivo de estudos, identifique o papel de cada linha e experimente mudar valores, nomes ou textos. Depois compare o resultado com o comportamento esperado.

Erro comum: copiar sem entender o que cada parte faz. Antes de avançar, tente explicar com suas palavras para que serve o recurso apresentado.

2. Indentação

Em Python, a indentação define os blocos. Linhas pertencentes a um if, for ou função devem manter recuo consistente, geralmente quatro espaços.

3. Variáveis e tipos

Variáveis armazenam referências a valores. Tipos comuns incluem int, float, str e bool. type() informa o tipo de um valor.

4. Entrada e saída

input() recebe texto digitado; print() mostra mensagens. Converta com int() ou float() antes de realizar cálculos numéricos.

Exemplo explicado

print("Você tem", idade, "anos")
