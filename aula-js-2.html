📖 Conteúdo da aula

Estude cada tópico com atenção. Não precisa decorar tudo: entenda os exemplos e pratique as ideias.

1. if e else

Condições permitem executar caminhos diferentes conforme uma expressão booleana. Use blocos com chaves para deixar a lógica explícita.

Exemplo explicado

if (nota >= 7) {
  console.log("Aprovado");
} else {
  console.log("Revisar");
}

Como praticar: copie o exemplo em um arquivo de estudos, identifique o papel de cada linha e experimente mudar valores, nomes ou textos. Depois compare o resultado com o comportamento esperado.

Erro comum: copiar sem entender o que cada parte faz. Antes de avançar, tente explicar com suas palavras para que serve o recurso apresentado.

2. else if

Quando há várias faixas de resultado, encadeie condições com else if. A ordem importa: a primeira condição verdadeira é executada.

Exemplo explicado

if (nota >= 9) { console.log("Ótimo"); }
else if (nota >= 7) { console.log("Bom"); }
else { console.log("Estude mais"); }

Como praticar: copie o exemplo em um arquivo de estudos, identifique o papel de cada linha e experimente mudar valores, nomes ou textos. Depois compare o resultado com o comportamento esperado.

Erro comum: copiar sem entender o que cada parte faz. Antes de avançar, tente explicar com suas palavras para que serve o recurso apresentado.

3. Comparações

=== compara valor e tipo; == faz conversões implícitas e pode confundir. Para comparar números recebidos como texto, converta-os explicitamente.

Exemplo explicado

const resposta = Number("10");
console.log(resposta === 10);

Como praticar: copie o exemplo em um arquivo de estudos, identifique o papel de cada linha e experimente mudar valores, nomes ou textos. Depois compare o resultado com o comportamento esperado.

Erro comum: copiar sem entender o que cada parte faz. Antes de avançar, tente explicar com suas palavras para que serve o recurso apresentado.

4. switch e ternário

switch é útil para opções discretas; o operador ternário escolhe entre dois valores em uma expressão simples. Prefira if quando a decisão for complexa.

Exemplo explicado

const status = pontos > 0 ? "Iniciado" : "Novo";

Como praticar: copie o exemplo em um arquivo de estudos, identifique o papel de cada linha e experimente mudar valores, nomes ou textos. Depois compare o resultado com o comportamento esperado.
