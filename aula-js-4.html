📖 Conteúdo da aula

Estude cada tópico com atenção. Não precisa decorar tudo: entenda os exemplos e pratique as ideias.

1. Funções

Uma função agrupa instruções reutilizáveis. Parâmetros recebem valores e return devolve um resultado para quem chamou.

Exemplo explicado

function somar(a, b) {
  return a + b;
}
const total = somar(2, 3);

Como praticar: copie o exemplo em um arquivo de estudos, identifique o papel de cada linha e experimente mudar valores, nomes ou textos. Depois compare o resultado com o comportamento esperado.

Erro comum: copiar sem entender o que cada parte faz. Antes de avançar, tente explicar com suas palavras para que serve o recurso apresentado.

2. Escopo

Variáveis declaradas dentro de uma função geralmente só podem ser acessadas nela. Isso evita conflitos entre partes do programa.

Exemplo explicado

  const mensagem = "Olá";
  return mensagem;
}

3. Arrays

Arrays guardam coleções ordenadas. Os índices começam em zero; length informa a quantidade de itens; push acrescenta ao final.

Exemplo explicado

const cursos = ["HTML", "CSS"];
cursos.push("Python");
console.log(cursos[0]);

Como praticar: copie o exemplo em um arquivo de estudos, identifique o papel de cada linha e experimente mudar valores, nomes ou textos. Depois compare o resultado com o comportamento esperado.

4. Métodos de arrays

map transforma itens em uma nova lista; filter seleciona itens; forEach percorre itens. Entenda a diferença entre produzir uma lista e apenas executar uma ação.

Exemplo explicado

const notas = [5, 8, 10];
const aprovadas = notas.filter(n => n >= 7);
