📖 Conteúdo da aula

Estude cada tópico com atenção. Não precisa decorar tudo: entenda os exemplos e pratique as ideias.

1. Formulários

form agrupa controles. input recebe dados; label identifica o campo; textarea aceita textos maiores; select apresenta opções. name identifica os valores enviados.

Exemplo explicado

<form>
<label for="nome">Nome</label>
<input id="nome" name="nome" required>
<button type="submit">Enviar</button>
</form>

Como praticar: copie o exemplo em um arquivo de estudos, identifique o papel de cada linha e experimente mudar valores, nomes ou textos. Depois compare o resultado com o comportamento esperado.

Erro comum: copiar sem entender o que cada parte faz. Antes de avançar, tente explicar com suas palavras para que serve o recurso apresentado.

2. Tipos de entrada

input type="email" oferece validação básica de e-mail; type="number" aceita números; type="radio" permite escolher uma opção do mesmo grupo; checkbox permite marcar alternativas independentes.

Exemplo explicado

<label>E-mail <input type="email" name="email" required></label>
<label><input type="checkbox" name="aceite"> Aceito os termos</label>

Como praticar: copie o exemplo em um arquivo de estudos, identifique o papel de cada linha e experimente mudar valores, nomes ou textos. Depois compare o resultado com o comportamento esperado.

Erro comum: copiar sem entender o que cada parte faz. Antes de avançar, tente explicar com suas palavras para que serve o recurso apresentado.

3. Validação nativa

required exige preenchimento; minlength estabelece mínimo de caracteres; min e max definem limites numéricos. A validação do navegador ajuda, mas não substitui validação no servidor em sistemas reais.

Exemplo explicado

<input name="usuario" required minlength="3">
<input type="number" min="1" max="10">

Como praticar: copie o exemplo em um arquivo de estudos, identifique o papel de cada linha e experimente mudar valores, nomes ou textos. Depois compare o resultado com o comportamento esperado.

Erro comum: copiar sem entender o que cada parte faz. Antes de avançar, tente explicar com suas palavras para que serve o recurso apresentado.

4. Projeto integrador

Monte uma página com cabeçalho, navegação, título, imagem, lista, tabela, formulário e rodapé. Revise a semântica, os textos alternativos e os links antes de apresentar.

Exemplo explicado

<main>
<h1>Meu portfólio</h1>
<section><h2>Projetos</h2><ul><li>Meu primeiro site</li></ul></section>
</main>

Como praticar: copie o exemplo em um arquivo de estudos, identifique o papel de cada linha e experimente mudar valores, nomes ou textos. Depois compare o resultado com o comportamento esperado.
