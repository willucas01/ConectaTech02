📖 Conteúdo da aula

Estude cada tópico com atenção. Não precisa decorar tudo: entenda os exemplos e pratique as ideias.

1. Design responsivo

Um layout responsivo se adapta a celular, tablet e computador. Prefira larguras flexíveis, imagens com max-width e componentes que possam quebrar linha.

Exemplo explicado

img { max-width: 100%; height: auto; }

Como praticar: copie o exemplo em um arquivo de estudos, identifique o papel de cada linha e experimente mudar valores, nomes ou textos. Depois compare o resultado com o comportamento esperado.

Erro comum: copiar sem entender o que cada parte faz. Antes de avançar, tente explicar com suas palavras para que serve o recurso apresentado.

2. Media queries

@media permite aplicar regras conforme características da tela. Comece com um layout simples e amplie quando houver espaço.

Exemplo explicado

@media (max-width: 700px) { .cards { grid-template-columns: 1fr; } }

Como praticar: copie o exemplo em um arquivo de estudos, identifique o papel de cada linha e experimente mudar valores, nomes ou textos. Depois compare o resultado com o comportamento esperado.

Erro comum: copiar sem entender o que cada parte faz. Antes de avançar, tente explicar com suas palavras para que serve o recurso apresentado.

3. Estados e interações

Pseudo-classes como :hover, :focus-visible e :checked estilizam estados. :focus-visible é importante para quem navega com teclado.

Exemplo explicado

a:hover { color: cyan; }
a:focus-visible { outline: 3px solid yellow; }

Como praticar: copie o exemplo em um arquivo de estudos, identifique o papel de cada linha e experimente mudar valores, nomes ou textos. Depois compare o resultado com o comportamento esperado.

Erro comum: copiar sem entender o que cada parte faz. Antes de avançar, tente explicar com suas palavras para que serve o recurso apresentado.

4. Transições e projeto

transition suaviza alterações; border-radius arredonda cantos; box-shadow cria profundidade. Respeite preferências de movimento reduzido quando houver animações.

Exemplo explicado

.botao { transition: background .2s; border-radius: 12px; }
@media (prefers-reduced-motion: reduce) { * { transition: none; } }

Como praticar: copie o exemplo em um arquivo de estudos, identifique o papel de cada linha e experimente mudar valores, nomes ou textos. Depois compare o resultado com o comportamento esperado.
