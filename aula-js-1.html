1. O que é JavaScript

JavaScript é uma linguagem de programação usada para tornar páginas interativas. Neste site, você apenas estuda exemplos: a plataforma foi construída sem JavaScript.

Exemplo explicado

// Exemplo didático, não executado pelo site
console.log("Olá, mundo!");

Como praticar: copie o exemplo em um arquivo de estudos, identifique o papel de cada linha e experimente mudar valores, nomes ou textos. Depois compare o resultado com o comportamento esperado.

Erro comum: copiar sem entender o que cada parte faz. Antes de avançar, tente explicar com suas palavras para que serve o recurso apresentado.

2. Variáveis

let declara uma variável cujo valor pode mudar; const declara uma referência que não pode ser reatribuída. Escolha nomes claros e evite var em código moderno.

Exemplo explicado

const curso = "JavaScript";
let pontos = 0;
pontos = pontos + 10;

Como praticar: copie o exemplo em um arquivo de estudos, identifique o papel de cada linha e experimente mudar valores, nomes ou textos. Depois compare o resultado com o comportamento esperado.

Erro comum: copiar sem entender o que cada parte faz. Antes de avançar, tente explicar com suas palavras para que serve o recurso apresentado.

3. Tipos de dados

string representa texto, number representa números, boolean representa verdadeiro ou falso, null indica ausência intencional e undefined representa valor ainda não definido.

Exemplo explicado

const nome = "Ana";
const idade = 18;
const aprovado = true;

Como praticar: copie o exemplo em um arquivo de estudos, identifique o papel de cada linha e experimente mudar valores, nomes ou textos. Depois compare o resultado com o comportamento esperado.

4. Operadores

Use +, -, *, / para contas; === para igualdade estrita; !== para diferença; && e || para combinar condições.

Exemplo explicado

const nota = 8;
const passou = nota >= 7 && nota <= 10;

Como praticar: copie o exemplo em um arquivo de estudos, identifique o papel de cada linha e experimente mudar valores, nomes ou textos. Depois compare o resultado com o comportamento esperado.
