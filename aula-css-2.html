📖 Conteúdo da aula

Estude cada tópico com atenção. Não precisa decorar tudo: entenda os exemplos e pratique as ideias.

1. Cores

Você pode usar nomes de cores, hexadecimal, rgb() ou hsl(). Garanta contraste suficiente entre texto e fundo para facilitar a leitura.

Exemplo explicado

body { background: #071a38; color: #ffffff; }

Como praticar: copie o exemplo em um arquivo de estudos, identifique o papel de cada linha e experimente mudar valores, nomes ou textos. Depois compare o resultado com o comportamento esperado.

Erro comum: copiar sem entender o que cada parte faz. Antes de avançar, tente explicar com suas palavras para que serve o recurso apresentado.

2. Tipografia

font-family escolhe a fonte; font-size controla o tamanho; font-weight define peso; line-height controla o espaço entre linhas. Evite parágrafos muito largos.

Exemplo explicado

body { font-family: Arial, sans-serif; line-height: 1.7; }
h1 { font-size: 2rem; }

Como praticar: copie o exemplo em um arquivo de estudos, identifique o papel de cada linha e experimente mudar valores, nomes ou textos. Depois compare o resultado com o comportamento esperado.

Erro comum: copiar sem entender o que cada parte faz. Antes de avançar, tente explicar com suas palavras para que serve o recurso apresentado.

3. Modelo de caixa

Todo elemento ocupa uma caixa com conteúdo, padding, border e margin. padding é o espaço interno; margin é o espaço externo. box-sizing: border-box simplifica medidas.

Exemplo explicado

* { box-sizing: border-box; }
.card { padding: 20px; border: 1px solid #38bdf8; margin: 16px; }

Como praticar: copie o exemplo em um arquivo de estudos, identifique o papel de cada linha e experimente mudar valores, nomes ou textos. Depois compare o resultado com o comportamento esperado.

Erro comum: copiar sem entender o que cada parte faz. Antes de avançar, tente explicar com suas palavras para que serve o recurso apresentado.

4. Unidades

px é fixo em pixels CSS; rem é relativo ao tamanho da fonte raiz; % depende da referência; vw usa a largura da viewport. Use unidades relativas quando fizer sentido.

Exemplo explicado

.container { width: 90%; max-width: 1100px; margin: auto; }

Como praticar: copie o exemplo em um arquivo de estudos, identifique o papel de cada linha e experimente mudar valores, nomes ou textos. Depois compare o resultado com o comportamento esperado.
