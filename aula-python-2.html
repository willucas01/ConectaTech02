📖 Conteúdo da aula

Estude cada tópico com atenção. Não precisa decorar tudo: entenda os exemplos e pratique as ideias.

1. Operadores aritméticos

Use +, -, *, /, //, % e **. A divisão / retorna um número de ponto flutuante; // faz divisão inteira por piso; % retorna o resto.

Exemplo explicado

print(10 // 3)  # 3
print(10 % 3)   # 1
print(2 ** 3)   # 8

Como praticar: copie o exemplo em um arquivo de estudos, identifique o papel de cada linha e experimente mudar valores, nomes ou textos. Depois compare o resultado com o comportamento esperado.

Erro comum: copiar sem entender o que cada parte faz. Antes de avançar, tente explicar com suas palavras para que serve o recurso apresentado.

2. Comparações

== testa igualdade, != testa diferença, > e < comparam valores e >= e <= incluem a igualdade. Expressões de comparação produzem booleanos.

Exemplo explicado

nota = 8
print(nota >= 7)

Como praticar: copie o exemplo em um arquivo de estudos, identifique o papel de cada linha e experimente mudar valores, nomes ou textos. Depois compare o resultado com o comportamento esperado.

Erro comum: copiar sem entender o que cada parte faz. Antes de avançar, tente explicar com suas palavras para que serve o recurso apresentado.

3. if, elif e else

Condições permitem decisões. elif significa senão se; else cobre os casos restantes. A indentação indica o conteúdo de cada ramo.

Exemplo explicado

if nota >= 9:
    print("Excelente")
elif nota >= 7:
    print("Aprovado")
else:
    print("Revisar")

Como praticar: copie o exemplo em um arquivo de estudos, identifique o papel de cada linha e experimente mudar valores, nomes ou textos. Depois compare o resultado com o comportamento esperado.

Erro comum: copiar sem entender o que cada parte faz. Antes de avançar, tente explicar com suas palavras para que serve o recurso apresentado.

4. Operadores lógicos

and exige que as duas condições sejam verdadeiras; or exige ao menos uma; not inverte um booleano. Use parênteses para facilitar expressões complexas.

Exemplo explicado

idade = 19
possui_documento = True
print(idade >= 18 and possui_documento)

Como praticar: copie o exemplo em um arquivo de estudos, identifique o papel de cada linha e experimente mudar valores, nomes ou textos. Depois compare o resultado com o comportamento esperado.
