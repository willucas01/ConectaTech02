1. Por que criar outra linguagem de programação

No fim dos anos 1980, programar muitas tarefas exigia escrever código longo e pouco expressivo. Guido van Rossum queria uma linguagem com sintaxe legível, produtiva e capaz de integrar ferramentas. Python surgiu nesse contexto, influenciado pela linguagem ABC e por ideias de simplicidade e extensibilidade.

2. Quem criou Python

Guido van Rossum começou a trabalhar em Python no final de 1989, no centro de pesquisa CWI, nos Países Baixos. A primeira versão pública foi disponibilizada em 1991. Ele liderou o desenvolvimento por muitos anos e ficou conhecido como Benevolent Dictator For Life (BDFL), título do qual se afastou em 2018.

3. De onde vem o nome Python

O nome não foi inspirado originalmente na cobra, mas no grupo de comédia britânico Monty Python. A escolha refletia o desejo de um nome curto, memorável e divertido. O símbolo da cobra acabou se tornando parte da identidade visual da linguagem.

4. Filosofia de legibilidade

Python valoriza código que possa ser lido e entendido com facilidade. Blocos são definidos pela indentação, não por chaves. O famoso texto Zen of Python reúne princípios como clareza e simplicidade. Essas escolhas ajudam iniciantes, mas exigem atenção a espaços, nomes de variáveis e organização das funções.

5. Python 2 e Python 3

Python evoluiu por muitas versões. Python 3 foi lançado em 2008 para corrigir limitações históricas e melhorar o projeto da linguagem, mas trouxe incompatibilidades com parte do código Python 2. O suporte oficial a Python 2 terminou em 2020. Para novos estudos e projetos, a família Python 3 é a escolha adequada.

6. Como o código é executado

Na implementação mais comum, CPython, o código-fonte é analisado e convertido em bytecode executado pela máquina virtual do interpretador. Para o iniciante, basta entender que um arquivo .py pode ser executado por um interpretador Python. Ferramentas como IDLE e VS Code ajudam a editar, executar e depurar os programas.

7. Onde Python é usado

Python aparece em automação, análise de dados, ciência, aprendizado de máquina, aplicações Web, testes e educação. Bibliotecas como pandas e NumPy apoiam análise numérica; frameworks como Django e Flask são usados em serviços Web. A linguagem não é a melhor escolha para todo problema, mas sua versatilidade é uma vantagem.

8. Bibliotecas e comunidade

Uma das forças de Python é sua biblioteca padrão, que oferece recursos para arquivos, datas, matemática, texto e redes. O gerenciador pip permite instalar pacotes de terceiros. Ambientes virtuais isolam dependências entre projetos. A Python Software Foundation apoia a comunidade e o desenvolvimento do ecossistema.

9. Impacto de Python na educação e na ciência

A sintaxe legível favoreceu o ensino de programação e a criação de pequenos programas úteis. Em pesquisa e ciência de dados, ferramentas do ecossistema aceleraram experimentos, visualizações e análises.
