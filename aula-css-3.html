Flexbox e Grid

📖 Conteúdo da aula

Estude cada tópico com atenção. Não precisa decorar tudo: entenda os exemplos e pratique as ideias.

1. Display e fluxo

Elementos block costumam ocupar a largura disponível; inline compartilham a linha; flex e grid criam sistemas de layout. display:none remove o elemento do fluxo.

Exemplo explicado

.menu { display: flex; }

Como praticar: copie o exemplo em um arquivo de estudos, identifique o papel de cada linha e experimente mudar valores, nomes ou textos. Depois compare o resultado com o comportamento esperado.

Erro comum: copiar sem entender o que cada parte faz. Antes de avançar, tente explicar com suas palavras para que serve o recurso apresentado.

2. Flexbox

Flexbox organiza itens em uma dimensão. justify-content distribui no eixo principal; align-items alinha no eixo transversal; gap cria espaço entre itens.

Exemplo explicado

.menu { display: flex; justify-content: space-between; align-items: center; gap: 16px; }

Como praticar: copie o exemplo em um arquivo de estudos, identifique o papel de cada linha e experimente mudar valores, nomes ou textos. Depois compare o resultado com o comportamento esperado.

Erro comum: copiar sem entender o que cada parte faz. Antes de avançar, tente explicar com suas palavras para que serve o recurso apresentado.

3. CSS Grid

Grid organiza linhas e colunas. repeat() evita repetição e minmax() ajuda a criar colunas adaptáveis.

Exemplo explicado

.cards { display: grid; grid-template-columns: repeat(2, minmax(0, 1fr)); gap: 20px; }

Como praticar: copie o exemplo em um arquivo de estudos, identifique o papel de cada linha e experimente mudar valores, nomes ou textos. Depois compare o resultado com o comportamento esperado.

Erro comum: copiar sem entender o que cada parte faz. Antes de avançar, tente explicar com suas palavras para que serve o recurso apresentado.

4. Posicionamento

position: relative estabelece referência para elementos absolute. fixed acompanha a viewport; sticky pode prender um elemento ao rolar. Use posicionamento com intenção.

Exemplo explicado

.selo { position: absolute; top: 12px; right: 12px; }

Como praticar: copie o exemplo em um arquivo de estudos, identifique o papel de cada linha e experimente mudar valores, nomes ou textos. Depois compare o resultado com o comportamento esperado.
