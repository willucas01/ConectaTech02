🎮 ConectaTech
Aprenda. Jogue. Evolua.

O ConectaTech é um projeto acadêmico de plataforma web de aprendizagem em tecnologia, que combina conteúdos introdutórios de programação com uma interface inspirada em jogos e aventuras.

A proposta é tornar o primeiro contato com tecnologia mais acessível, visual e envolvente para estudantes e iniciantes.

🚀 Sobre o projeto
O site organiza o aprendizado em mundos temáticos, com trilhas que reúnem aulas, exercícios e etapas de conclusão. A identidade visual utiliza elementos de jogos, como fases, personagens, conquistas e XP.
Estado atual: protótipo front-end estático. Os elementos de progresso, XP e conquistas são apresentados visualmente; não há sistema de login, banco de dados ou persistência de progresso implementados neste pacote.

✨ O que você encontra
- 🏠 Página inicial: apresentação da plataforma e convite para explorar os cursos.
- 🌎 Mundos de aprendizagem: HTML5, CSS3, JavaScript e Python.
- 🗺️ Trilhas e fases: navegação por módulos e aulas de cada tecnologia.
- 📚 Aulas: conteúdos e exemplos introdutórios.
- 📝 Exercícios: questionários para praticar os assuntos apresentados.
- 🧑‍🚀 Personagens: tela visual de escolha de avatar.
- 🏆 Conquistas e XP: elementos visuais de gamificação.
🛠️ Tecnologias utilizadas
- HTML5 — estrutura e conteúdo das páginas.
- CSS3 — estilização, layout e recursos visuais.

O projeto disponibiliza conteúdos sobre JavaScript e Python, mas o pacote analisado não contém arquivos de implementação .js ou .py.

▶️ Como executar
Por ser um site estático, você não precisa instalar dependências.
1. Faça o download ou clone o repositório:
   git clone https://github.com/SEU-USUARIO/ConectaTech.git
2. Abra a pasta no Visual Studio Code.
3. Abra o arquivo index.html em um navegador ou utilize a extensão Live Server do VS Code.
4. Navegue entre os cursos, aulas e exercícios.
Substitua SEU-USUARIO pelo usuário do repositório no GitHub.

🎯 Objetivo acadêmico
Aplicar conceitos de desenvolvimento front-end, incluindo HTML semântico, CSS, navegação entre páginas, organização de arquivos e experiência do usuário, na criação de uma solução educativa com proposta de gamificação.
