📖 Conteúdo da aula

Estude cada tópico com atenção. Não precisa decorar tudo: entenda os exemplos e pratique as ideias.

1. for

O laço for repete um bloco enquanto a condição for verdadeira. Ele é útil quando você sabe quantas repetições deseja fazer.

Exemplo explicado

for (let i = 1; i <= 5; i++) {
  console.log(i);
}

Como praticar: copie o exemplo em um arquivo de estudos, identifique o papel de cada linha e experimente mudar valores, nomes ou textos. Depois compare o resultado com o comportamento esperado.

Erro comum: copiar sem entender o que cada parte faz. Antes de avançar, tente explicar com suas palavras para que serve o recurso apresentado.

2. while

while executa enquanto a condição permanecer verdadeira. Atualize as variáveis de controle para evitar repetição infinita.

Exemplo explicado

let contador = 0;
while (contador < 3) {
  contador++;
}

Como praticar: copie o exemplo em um arquivo de estudos, identifique o papel de cada linha e experimente mudar valores, nomes ou textos. Depois compare o resultado com o comportamento esperado.

Erro comum: copiar sem entender o que cada parte faz. Antes de avançar, tente explicar com suas palavras para que serve o recurso apresentado.

3. break e continue

break interrompe um laço; continue pula para a próxima iteração. Use com moderação para não dificultar a leitura.

Exemplo explicado

for (let n = 1; n <= 10; n++) {
  if (n === 5) break;
}

Como praticar: copie o exemplo em um arquivo de estudos, identifique o papel de cada linha e experimente mudar valores, nomes ou textos. Depois compare o resultado com o comportamento esperado.

Erro comum: copiar sem entender o que cada parte faz. Antes de avançar, tente explicar com suas palavras para que serve o recurso apresentado.

4. Depuração

Teste com entradas pequenas e confira os valores a cada repetição. Erros comuns são começar no índice errado e usar <= quando deveria usar <.

Exemplo explicado

for (let i = 0; i < 3; i++) {
  console.log("Índice", i);
}

Como praticar: copie o exemplo em um arquivo de estudos, identifique o papel de cada linha e experimente mudar valores, nomes ou textos. Depois compare o resultado com o comportamento esperado.

Erro comum: copiar sem entender o que cada parte faz. Antes de avançar, tente explicar com suas palavras para que serve o recurso apresentado.
